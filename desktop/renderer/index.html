Connexion au Pi…

Recherche sur le réseau local puis Tailscale

--coût estimé / mois
--kWh sur la période
--en ligne

Choisis la mesure dans la liste. Glisse sur la courbe pour zoomer, double-clic pour revenir. Sur la température, glisse une ligne de seuil pour la régler.

Ces drapeaux viennent directement du firmware du Pi. « Depuis le démarrage » reste allumé jusqu’au prochain redémarrage.

Estimation à partir de la charge CPU. Le Pi n’a pas de wattmètre.

RéceptionÉmission

Raccourcis : Ctrl+K commandes, 1 à 6 changent de page, T le thème, R actualise. Partout dans Windows : Ctrl+Alt+P ouvre ou masque l’app, Ctrl+Alt+W les widgets.

Glisse un widget pour le déplacer. Clic droit dessus pour l’opacité, changer de widget ou le fermer. Sa position est mémorisée.
